# 🎮 MCJHub

> **Minecraft Java Hub** — gerenciamento simples, rápido e centralizado para os arquivos do Minecraft Java Edition.

O **MCJHub** é uma aplicação desenvolvida para facilitar o gerenciamento dos arquivos do **Minecraft Java Edition**, reunindo diversas ferramentas úteis em um único lugar.

Gerencie seus **mundos, mods, backups, shaders, texturas e outros arquivos** de forma mais simples, organizada e prática.

---

## ✨ Funcionalidades

O MCJHub busca centralizar tarefas que normalmente precisam ser realizadas manualmente.

- 🔄 **Atualização de mods**
- 🗺️ **Cópia e gerenciamento de mundos/mapas**
- 💾 **Criação e restauração de backups**
- 📦 **Organização dos arquivos do Minecraft**
- 🎨 **Gerenciamento de Shaders e Texturas**
- ⚙️ **Gerenciamento centralizado em uma única aplicação**
- 🚀 **Automatização de tarefas repetitivas**

---

## 🎯 Objetivo

O principal objetivo do **MCJHub** é tornar o gerenciamento do Minecraft mais **prático, rápido e organizado**.

A aplicação busca reduzir tarefas manuais e repetitivas, como:

- Criar e restaurar backups;
- Instalar e atualizar modificações;
- Gerenciar mundos;
- Instalar Shaders;
- Instalar pacotes de Texturas;
- Organizar arquivos do Minecraft.

> 💡 **Tudo em um único lugar.**
