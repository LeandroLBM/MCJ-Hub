MCJHub

Minecraft Java Hub é uma aplicação desenvolvida para facilitar o gerenciamento dos arquivos do Minecraft Java Edition.

O objetivo do MCJHub é reunir ferramentas úteis em um único lugar, permitindo que o usuário gerencie seus mundos, modificações e backups de forma simples e organizada.

[✨ Funcionalidades]

🔄 Atualização de modificações/mods
🗺️ Cópia e gerenciamento de mapas
💾 Criação e restauração de backups
📦 Organização dos arquivos do Minecraft
⚙️ Gerenciamento centralizado através de uma única aplicação
🎯 Objetivo

O MCJHub busca tornar o gerenciamento do Minecraft mais prático, evitando que o usuário precise realizar manualmente tarefas como copiar mundos ou criar backups.

🖥️ Plataforma
Atualmente, o MCJHub é desenvolvido para Windows, sendo distribuído como uma aplicação .exe.
